# FlowBoard — 15-Day Dev Plan

One file per day, mapped directly to the milestones in `flowboard-project-brief.docx.md` and the walkthroughs in `nodejs-part2-trainee-v4.docx.md`.

Each day file contains:

1. **Task** — the concrete deliverable for that day.
2. **Dev Plan** — files, signatures, schemas, edge cases, tests.
3. **Commit** — the exact commit-message tag from the brief.
4. **Workflow Prompt** — a `/workflow` invocation you can paste in to start the Explore → Plan → Act → Verify loop.
